【文物精灵 · AI 文物识别 · 演示应急卡】(可打印 / 拍照备用)

◆ 换个电脑演示(离开本机电脑)
  1. 拷贝整个「文物精灵」文件夹 → 演示电脑;钥匙已随文件夹带好(js\ident-direct.js)
     · 演示电脑若装了 Python:双击 tools\start_ident_cloud.bat 开小桥最稳;页面上粘一次钥匙会自动同步给桥(只存内存)
     · 若拷的是「提交包」(tools\make_submission.py 生成),钥匙已清空:现场点「🔑 粘贴密钥」即可,或提前准备本机演示
  2. 双击 index.html(Chrome / Edge 都行)
  3. 上传文物照片 → 页面最上方出「☁️ 云端识别结果」
     · 认出后:结果卡里直接亮出对应精灵的 Q 版立绘,点「⚡ 唤醒它」当场收进图鉴(识别 → 唤醒闭环,演示高光)
     · 若卡片提示要钥匙:点「🔑 粘贴密钥」,把 AI 钥匙整条粘一次(智谱 id.secret 或 方舟 ark-;只存那台电脑浏览器里;开着本机小桥时还会自动同步给桥,三件套全通)
     · 前提:演示电脑能上网(智谱钥匙即插即用、全场免费;方舟钥匙需账号已开通豆包视觉模型,见下)

◆ 拿钥匙(只做一次 · 手机可做;推荐智谱,全场免费)
  1. open.bigmodel.cn 登录(手机号注册,不用充值)→ 控制台「API Key」新建一把(形如 id.secret)
     · 这一把钥匙管全套:识别 / 茶话会 / 拍照幻化(CogView 出图),全部免费用
  2. (可选 · 改用火山方舟)console.volcengine.com/ark 登录 →「开通管理」开通任意一个豆包视觉模型(有免费额度)
     · 幻化若要走方舟,还需开通 Doubao-Seedream-5.0-flash(¥0.12/张,需账号有余量;不开也能演示——幻化会自动走免费 CogView 或本机国风卡)
  3. 回网页点「🔄 重试云端识别」——不用改钥匙、不用重启任何东西(小桥会自动挑免费 / 已开通的模型)

◆ 本机演示
  · 双击 tools\start_ident_cloud.bat 开小桥(推荐),或直接双击 index.html 走直连
  · 状态看页面上「☁️ 云端识别:…」一行
  · 拍照幻化 / 识别 / 茶话会都优先走本机小桥(最稳);浏览器直连在部分网络会被云端预检拦下,尽量开着桥演示
  · 右下角小答的「文物知识问答」也走云端(智谱免费):问「铁狮子有多重」「长信宫灯是什么」会现场作答并标注模型;没开桥时自动回退本地话术,聊天不断
  · 别人连你 WiFi 一起玩:双击 tools\start_lan.bat,把窗口里打印的局域网地址(形如 http://192.168.x.x:8899/文物精灵/)发给对方即可;手机建议用「选择照片」上传(手机浏览器 http 下相机常被禁用)

◆ 万一没网 / 没钥匙
  · 上传后本机引擎照常出:修复对比 + 器型 / 纹样 / 年代 / 材质四项 + 相近候选,流程不断
  · 拍照幻化自动改用本机国风艺术化(约 1 秒),流程不断
  · 「⚡ 唤醒」跟着云端识别结果走:没网时先用本机结果,联网后点「🔄 重试云端识别」再唤醒

◆ 安全
  · js\ident-direct.js 含密钥:比赛提交 / 外发前清空或删掉即可(删后仍能现场「粘贴密钥」)
  · 一键清干净:跑 python tools\make_submission.py → 生成「文物精灵-提交包」(自动清空 + 扫描确认无密钥)
  · 要用环境变量(推荐):setx ZHIPU_API_KEY "你的id.secret"(重开终端生效),小桥优先读它;方舟用 ARK_API_KEY
