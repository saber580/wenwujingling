## 0:00–0:30 开场 · 一句话立意

**口播：**
大家好，我们是「文物精灵」团队。博物馆里最安静的地方，往往是观众流失最快的地方——一件国宝摆在展柜里，说明牌上只有一行年代和材质，大多数人拍张照就走了。我们想改变这件事：用 AI，让这些文物开口说话。文物精灵，是一个把全国 22 站、104 件馆藏文物，做成会聊天、有脾气的国风精灵的网站。接下来这几分钟，我们重点讲三件大多数同类作品做不到的事——照片不出本机就能识别文物、AI 说的每一句话都能查到出处、以及我们是怎么"问倒"自己的。

**画面：** 水墨片头 → 首页「山河长卷」大标题 → 快切三组文物实拍与 Q 版立绘对比
**字幕：** 让文物开口说话 —— 文物精灵 RELIC SOUL

## 0:30–1:30 第一件事 · 端侧 AI 识别，照片不出你的手机

**口播：**
第一个亮点，是文物识别。但请先注意一件事——我们用浏览器自带的 WebGPU 能力，把识别模型直接跑在**你自己的设备上**。你在博物馆拍一张照片，画面就在本机完成特征提取、PCA 白化和相似度比对，**照片根本不上传服务器**。这意味着什么？第一，隐私——文物的照片、你的位置，全程留在你自己手里；第二，速度——没有网络往返，识别耗时我们实测到了**毫秒级**。更关键的是第三点：这套识别不是调别人的 API，而是我们从零实现的——34 维剪影特征，降到 20 维做主成分分析，再用度量学习的方式，把 104 件文物的轮廓特征现场训练成分类头。模型、特征、比对，全部是自研的。

**画面：** 识宝页 → 上传照片 → 端侧识别进度条 → 结果卡片弹出「识别中·本机计算」角标 → 特写「照片不上传」→ 切一张技术图：34 维 → 20 维 → 度量学习
**字幕：** 端侧识别 · 照片不出本机 · 34 维剪影 → 20 维 PCA → 度量学习

## 1:30–2:30 第二件事 · 可溯源 RAG，AI 只负责表达

**口播：**
第二个亮点，回答「AI 凭什么可信」。多数 AI 文物问答，都是让大模型凭记忆发挥——看起来流畅，但数字可能是编的。我们的做法是反过来：**让 AI 只负责表达，让事实由检索兜底。** 站内 104 件文物的 1400 多段馆藏档案，先做 BM25 与 128 维语义的**双路检索**，再融合排序，找出最相关的原文；大模型只能**基于这些原文**组织语言，并且每句话后面都带一个角标，点一下就能追回到具体的档案、具体的字段、具体的原文。哪个数字有据可查、哪个是模型自己加的，一眼看得清。消融实验里，去掉检索兜底，命中率立刻从满分掉到九成——这一成，就是"AI 胡说"的那部分。

**画面：** 茶话会提问 → 流式回答逐字出现 → 光标悬停 `[n]` 角标 → 弹出档案原文与字段定位 → 技术图：BM25 + LSA(128维) → RRF 融合 → 溯源角标
**字幕：** 双路检索兜底 · 每句回答可追到档案原文 · 消融实验命中率 1.0 → 0.909

## 2:30–3:10 第三件事 · 对照实测，问倒自己

**口播：**
说"可控"不够，我们把验证做成了网站里的一个页面——「对照实测 · 问倒它」。同一个问题，并排跑两路：左边是**裸大模型**，右边是**我们的完整管线**。题目分三类：冷门文物、埋了错误前提的陷阱题、还有根本不存在的东西。结果很直接——面对查无此物的"铜鎏金麒麟熏炉"，裸模型会煞有介事地编出上百字的工艺细节，而我们的管线**两毫秒就判定弃答**，还会告诉你最相近的其实是铜鎏金凤凰脊兽，但它不顶替。这一页没有台本、实时在线，评委现在打开就能亲手试。

**画面：** 对照实测页 → 并排两栏同题 → 左栏「编造 149 字」vs 右栏「2ms 弃答」特写 → 评委可访问的二维码 / 网址
**字幕：** 同题并排 · 裸模型 vs 本站管线 · 实时在线可亲手验证

## 4:40–5:20 工程与安全

**口播：**
把这些撑起来的，是一个自研的 AI 接入层。第一，MCP 工具协议——任何支持 MCP 的客户端，都能直连我们开放的八个检索工具；第二，全端一致——手机和电脑是两套物理隔离的布局，改手机绝不动电脑；第三，安全——口令只存加盐哈希，AI 服务做来源校验，服务器补齐安全响应头，密钥全程不出本机；第四，输出可控——悬空引用、无依据的硬数字，会被自动摘除。流式输出下，首字响应控制在一到两秒。

## 附：录制与配音提示

1. **口播**：普通话，约 260 字/分钟；加粗句读处稍作停顿。全篇约 1500 字 ≈ 5 分 45 秒。
2. **分辨率**：录屏 1920×1080 及以上，浏览器缩放 100%，鼠标移动放慢。
3. **录屏顺序**照「画面」列走，每段多录 10 秒余量方便对位。
4. **字幕**：把每段「字幕」行做成 SRT，字号大、居下居中；技术术语（端侧识别 / RRF / 消融）与口播同步高亮。
5. **数字人**：开场与结尾各出镜 15–20 秒即可，中段以录屏为主；半身、正面、博物馆/书房背景。
6. **时长调节**：
   - 压缩到 5 分钟：删第 ⑤ 段的「心仪卡 / 主线故事」两句（约省 45 秒）。
   - 拉到 8 分钟：在第 ③ 段后加一段「幕后开发」——讲端侧识别从 CPU 版到 WebGPU 版的实测提速，以及双路检索的两个真实踩坑（讲稿可另出）。
