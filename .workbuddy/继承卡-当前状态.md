## 七、不能动的东西（动了会崩）

| 别动 | 原因 |
|---|---|
| `VN_STATIONS` / `VN_MAIN` 的自动构链机制 | choices/next/ending 是算出来的，手改会断链 |
| `vnLayout()` 坐标参数 | 112 节点按 5 列蛇形排布，改了会重叠 |
| `vnCamBox / vnCamPrep / vnFocusStation` | LOD 与取景耦合，改错会白屏或全图糊 |
| 精灵 id、站点 id | 立绘文件名、SPIRIT_DEEP key、流程图都靠它 |
| `css/style.css` 前面的旧规则 | 新样式都是末尾覆盖块，删旧的会连带影响别的页面 |
| `SPIRITS[id].era / intro`、`SPIRIT_DEEP[id].history` | 硬知识唯一来源，**改文本只能引用，不能编** |
