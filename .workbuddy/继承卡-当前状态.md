## 六、改写怎么做（最短路径）

1. 读 `交接卡-文本立意升级.md`
   - 第一节「立意圣经」：三层病灶（打卡拍照 / 家乡失联 / 文物被消费）
   - 第四节「七段式模板」：落地感官 → 当代切片 → 文物先给脾气 → 七友一句 → 玩家的空 → 三方向
   - 第五节「22 站设定表」：每站三只精灵各自的「意难平」，直接查表
2. 读 `js/aw-vn.js` 里**沧州那一块**（搜 `沧州 · 狮城问路`）——这是唯一合格的样本，语感、句长、知识出现的位置都以它为准
3. 在 `VN_ST_1..4` 数组里找到目标站，只改 `hub / caps[0..2] / win` 里的 `lines`
4. 改完跑三连校验，截图看效果，给用户看，再改下一站

**三条铁律**：
- 知识必须**跟在伤口后面**（先让人看见它裂了/没人问它，再说年代工艺）
- 七友**不是导游**，每个人有自己的私心（五铢钱爱算账、青花瓷讲究、宣纸怕火、象棋爱斗嘴……）
- 文物**必须反问玩家**，至少每站一次，问完让玩家答不上来

## 七、不能动的东西（动了会崩）

| 别动 | 原因 |
|---|---|
| `VN_STATIONS` / `VN_MAIN` 的自动构链机制 | choices/next/ending 是算出来的，手改会断链 |
| `vnLayout()` 坐标参数 | 112 节点按 5 列蛇形排布，改了会重叠 |
| `vnCamBox / vnCamPrep / vnFocusStation` | LOD 与取景耦合，改错会白屏或全图糊 |
| 精灵 id、站点 id | 立绘文件名、SPIRIT_DEEP key、流程图都靠它 |
| `css/style.css` 前面的旧规则 | 新样式都是末尾覆盖块，删旧的会连带影响别的页面 |
| `SPIRITS[id].era / intro`、`SPIRIT_DEEP[id].history` | 硬知识唯一来源，**改文本只能引用，不能编** |
