## 零、一句话任务

现在的主线**结构对了、文本是死的**。任务是把它从「到一个地方、某位朋友报年代、文物说『我认你』」的导航式介绍，
改写成**每只文物都有脾气、有伤口、有想说的话，玩家被它戳一下**的叙事。

判断标准只有一句：

> **玩家关掉游戏之后，会不会想起自己家乡博物馆里那件从没正眼看过的陶罐。**

## 一、立意圣经（不可动摇，所有文本都要往这三层上落）

### 病灶三层（要"演出来"，不要"说出来"）

| 层 | 现象 | 在游戏里怎么被看见 |
|---|---|---|
| 表层 | 文物被**消费**而非被**理解**。掏出手机咔嚓一张，配文"打卡成功"，转身就走。文物成了社交货币、九宫格里的一个像素 | 每站开场都有举着手机的游客，快门声比说话声响；文物开口第一句是"你不拍吗？" |
| 中层 | 青年与**家乡文物失联**——对故宫网红文物如数家珍，说不出家乡博物馆那件青铜器叫什么。地方文物"灯下黑" | 玩家有家乡设定。走到家乡站时，文物会问："你家门口的东西，你都不认识？" |
| 深层 | "让文物活起来"的本质不是加投影加 AR，是**让人和文物发生关系** | 玩家不是"点击查看简介"，是"认识一个朋友"。知识是混熟之后的赠礼，不是开场白 |

### 药方三条（写作纪律）

1. **不报名，先给脾气。** 文物出场的第一句话绝不能是"我叫XX，是XX朝代的XX器"。先让它嫌你、怼你、躲你、试探你，名字在第三四句才漏出来。
2. **知识是关系产物。** 年代、工艺、出土地这些硬信息，必须挂在"它为什么愿意告诉你"上。它先露一个伤口，你想接住，它才肯讲。**禁止百科式播报。**
3. **遗憾要留白。** 不是每个结局都皆大欢喜。有的文物你只能陪它坐一会儿，走的时候它没认你，但你说过的话它记住了。**"错过"比"收服"更接近真实。**

### 情感落点（终章必须打到）

不是"你收集了 66 只文物，恭喜通关"。
是"你走完 22 站，忽然想问：我家乡那件，它是不是也在等我。"

## 二、现状诊断：为什么现在"单调"

以下全部摘自当前 `js/aw-vn.js`，是**反例**，请勿沿用这种写法。

**病症 1 · 文物只会自我介绍**
```js
{ t: "say", id: "lvyoutaozhu", x: "呼……有人来啦？我叫绿釉陶猪。汉代人把我请进墓里，替墓主在那边备肉食。" }
```
一句里塞了名字、朝代、功能。这是展签，不是台词。

**病症 2 · 七友是导游，只会解说**
```js
{ t: "say", id: "wuzhuqian", x: "后周广顺三年铸的，现存最大的古代铸铁艺术品之一。它张嘴不是吼人，是吼潮。" }
```
五铢钱在这里和百度百科没有区别。它应该是"见过太多人为了钱卖掉祖产"的那个抠门老账房，不是讲解员。

**病症 3 · 玩家是透明人**
全文 409 行台词，玩家没有说过一句话，没有名字、没有家乡、没有身份。玩家只是一个"点击继续"的手指。

**病症 4 · 三选一没有冲突，只有路线**
```js
{ label: "镇海之路", text: "（握紧玉坠）先向东。海边的铁狮子，我要亲眼去看看。" }
```
三个选项的差别只是"先看哪只"。真正的分支应该差在**玩家怎么面对这件事**：是迎上去、是问到底、还是坐下来陪它。

**病症 5 · 当代性完全缺席**
"打卡拍照""朋友圈""网红展"——一次都没出现。可是这正是要批判的东西。**没有当代对照，批判就落空。**

**病症 6 · 结局一律是"我认你"**
```js
{ t: "say", id: "tielion", x: "……你不躲。好。这一站，吾认你。" }
```
66 个站内结局全是同一句话的变体。没有一次"它没理你"。

**病症 7 · 文物从不问回去**
所有对话都是单向的：文物讲，玩家听。没有人问"你是谁""你从哪来""你家乡有什么"。

**病症 8 · 句法同质，读者能预判下一句**
每站都是：车马停下 → 图鉴亮起三处微光 → 某友解释 → 文物开口 → 认你。
读到第三站，读者已经知道第五站长什么样。**这是"单调"的根因。**

## 三、五根新骨头（改造方案）

### 3.1 文物档案升级：`VN_VOICE` 新表

在 `js/aw-vn.js` 顶部（`VN_OPEN` 之前）新增一张表，为**三只站内精灵 + 七友 + 国博/终章主文物**建档：

```js
/* 文物人格档案：每只文物五件事 —— 想要的、怕的、意难平、最想让人知道的一件事、反问玩家的一句话 */
const VN_VOICE = {
  tielion: {
    want:  "有人问一句它叫什么",
    fear:  "被叫成『那个大铁疙瘩』",
    wound: "它身上早就裂了，靠一圈钢架撑着。所有人夸它『最大最老』，没有一个人看出它在硬撑",
    tell:  "后周广顺三年铸，不是为好看，是为了压住这一带的水患。它张嘴不是吼人，是吼潮",
    ask:   "你家那边，有没有像我这样，站得太久没人问的老东西？",
  },
  // ...
};
```

字段含义与用法（**这是本卡最关键的约定**）：
- `want` / `fear` → 决定它开场怎么对你（想要被问，就会先冷冷问"你不拍吗"）
- `wound` → 全站情感高点，必须在 cap 节点的第 3–4 句露出
- `tell` → 硬知识，**只能挂在 wound 之后**，由它自己说出来
- `ask` → 每站 `win` 节点的最后一句，反问玩家

### 3.2 玩家身份：家乡设定（解决"青年不了解家乡文物"）

- 新增 `VN.player = { name: "", hometown: "" }`，存 `localStorage`（key 建议 `wjwl_vn_player_v1`）
- 开场「七友相送」之后加一个**极短**的问答节点：玉坠问"你是哪儿人？" → 给出 11 个河北站 + "我是外省的"
- 走到家乡站时，该站 `hub` 自动追加 3 行「家门口的质问」：
  ```js
  { t: "narr", x: "你忽然想起来——小时候春游来过这儿。你只记得门口卖的冰棍。" },
  { t: "say", id: "tielion", x: "你家门口的东西，你都不认识？" },
  { t: "narr", x: "你说不出话。它也没再追问，只是把眼睛往你这边偏了偏。" },
  ```
- 终章统计一句：`你走过 22 站，其中 1 站是你家乡的。你在那一站，站了很久。`
- **不需要新美术**，纯文本 + 一个判断 `if (VN.player.hometown === station.id)`。

### 3.3 「打卡 / 听懂」双反馈（把批判做成可操作的动作）

在每站 `hub` 的三选一**之前**，加一个只有一行的小动作按钮：

```js
photo: { label: "先拍张照", lines: [ ... ] }
```

玩家选了会发生什么（**三行，不能多**）：
```js
{ t: "narr", x: "你举起手机。取景框里，它被裁成一个方方正正的构图。" },
{ t: "say", id: "tielion", x: "……" },
{ t: "narr", x: "它不说话了。风把锈屑吹到你鞋面上。你忽然觉得这张照片，拍了跟没拍一样。" },
```
然后**自动回到三选一**（不消耗机会，但玩家心里被扎了一下）。
- 这是"反打卡"的机制化表达：不是禁止拍照，是让你尝到"拍完什么也没带走"的空。
- 若某站玩家连续两次选"先拍张照"，追加一句七友的吐槽（银器最合适："拍第二张？第一张你也没看。"）

### 3.4 七友性格弧线（七个导游变成七个活人）

七友必须各有缺陷，且在 22 站里**渐变**（不是每站一个样）。建议档案：

终章不再罗列收集品，改成：

2. 图鉴最后一页空白 → 所有人看着玩家
3. 玩家问："我家乡那件，还在吗？"
4. 玉坠答："在。它一直在。你只是没去看过。"
5. 结局卡文字：`【结局 · 灯下黑】你把 22 站的故事装进了图鉴。空了的那一格，是你家乡。`

## 四、每站七段式模板（照着填，就不会单调）

### hub 到站节点（6–9 行）
1. **落地感官**：气味/声音/光线，一句。不要写"车马停下"这种通用句
2. **当代切片**：游客、快门声、导游喇叭、文创店、自拍杆。**必须有**
3. **文物初现**：它在做什么？不报名，先给一个动作或一句脾气
4. **七友一句**：带性格，且只能由它说
5. **玩家的空**：一句 note，写出"我好像什么也没带走"的感觉
6. **三方向**：不是三个地点，是三种**面对方式**（见下）

### 三方向的正确写法

| 方向 | 不是 | 而是 | 结局调性 |
|---|---|---|---|
| 直面（勇） | "先去看铁狮子" | 你迎着它的沉默走上去，让所有人都看着你 | 被接纳，但代价是承担 |
| 追问（知） | "先翻图鉴查资料" | 你非要问出它为什么裂了、为什么不说话 | 得到知识，也戳到它痛处 |
| 相伴（情） | "先陪它坐一会儿" | 你什么都不问，就在旁边站着，等它自己开口 | 它没认你，但它记住了 |

三种结局的文案必须**三种不同情绪**，不能都是"吾认你"。
建议配比：直面=热血 6 : 沉重 4；追问=啊哈 7 : 冒犯 3；相伴=温 8 : 怅 2。

### cap 捕捉节点（5–7 行）
1. 靠近（一个具体的物理动作：绕到侧面、蹲下、伸手）
2. 它试探你（一句带刺的话）
3. **它露伤口**（`wound`，全站高点）
4. 你回应（写玩家的动作，不写台词，因为是玩家在选）
5. **它给知识**（`tell`，硬信息挂在这里）
6. 结缘 / 或不结缘（留遗憾）

### win 结缘节点（3–4 行）
1. 一句回响（它对你说的最后一句，别喊口号）
2. **`ask` 反问玩家**（家乡）
3. 下一站引子（不要"前往下一站"这种系统提示，用一句景物）

## 九、技术约束备忘

- 台词对象只有三种字段组合：`{ t:"narr", x:"..." }` / `{ t:"say", id:"精灵id", x:"..." }` / 新增 `{ t:"you", x:"..." }`
- `speaker` 字段是节点默认说话人（旁白时的立绘）
- `ask` 反问句**不要用引号包裹**整个字符串，双引号在中文里用「」更符合本项目语气
- 项目现有文风：短句、句号多、不堆形容词、少用感叹号
- 单句超过 70 字在手机上会挤，必须拆
- 所有硬知识以 `js/data.js` 的 `SPIRITS[id].era / intro` 和 `js/data-deep.js` 的 `SPIRIT_DEEP[id].history` 为准，**不许编年代**
